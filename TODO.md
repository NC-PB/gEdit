- [ ] **Tokenizer gaps, what is left**: an unclosed string or `[` runs to the line end (for `[` the comment mask disagrees); a Klartext `PLANE POINTS P1X+0` word (a digit inside the address, then a sign) is one unknown token; a Sinumerik jump written without a blank, `GOTOF:20`, still tokenizes as a label (Renumber and Remove Block Numbers follow it since the second M9 review round, which reads the main-block scan alone; hover and other readers see a label named `GOTOF`) ([tokenizer.ts](src/lib/core/nc/tokenizer.ts))
- [ ] **Tool-word variants, small gaps**: under the Okuma three-digit reading a six-digit word is not a tool change, and station names from the seven-digit form (`02`) and from `T2000` (`2`) are not normalised, so a file mixing both would split a tool in two (no real program does); under the Fanuc last-digit reading a short word `T1` is the station alone ([r6Variants.test.ts](src/lib/data/profiles/r6Variants.test.ts), [syntax-okuma §5.1](docs/planning/syntax/syntax-okuma.md#51-t-word))

The gap is written down in [dialects.md](docs/user/dialects.md#which-dialect-a-file-gets) and waits for a manual of the Okuma machining-centre control (low priority) ([contradiction.ts](src/lib/core/profiles/contradiction.ts))

- [ ] **Two tabs can own one file** (a symlink, `..`, or a mapped drive next to its UNC path) — the later save silently overwrites the earlier one ([documents.ts:30](src/lib/stores/documents.ts#L30-L46))
